# 导入报告

**材料**：《(仅高)数学学科教学论简答题资料整理（高级中学）》（21 页 PDF，约 1.7 万字）
**主题**：`math-teaching-theory` — 数学学科教学论（高级中学）

**笔记拆分（按概念原子化，共 24 篇）**

课标（11）：
- `core-literacy-answer-structure` — 核心素养题的通用答题结构（四段式）
- `core-literacy-math-abstraction` — 数学抽象核心素养
- `core-literacy-logical-reasoning` — 逻辑推理核心素养
- `core-literacy-mathematical-modeling` — 数学建模核心素养
- `core-literacy-intuitive-imagination` — 直观想象核心素养
- `core-literacy-mathematical-operation` — 数学运算核心素养
- `hs-math-curriculum-nature` — 高中数学课程的性质：基础性、选择性、发展性
- `four-bases-curriculum-goal` — "四基"课程目标：基础知识、基本技能、基本思想、基本活动经验
- `curriculum-structure-basis` — 高中课程结构设计的四方面依据
- `situation-problem-diversity` — 教学情境的多样性 与 数学问题的多层次性
- `teaching-evaluation-principles` — 学习评价的四条原则

教学知识（7）：
- `common-teaching-methods` — 三种常用教学方法：讲授法、谈话法、发现法
- `student-learning-modes` — 数学中常见的三种学习方式
- `concept-definition-methods` — 数学概念的两种定义方式：属加种差 与 揭示外延
- `math-thinking-methods` — 三种常用数学思想方法：转化与化归、分类讨论、数形结合
- `cultivating-math-thinking` — 培养数学思想的三条路径
- `theorem-teaching-stages` — 数学定理教学的基本环节
- `textbook-material-selection` — 教材素材选取的要求

教学设计与案例分析（6）：
- `teaching-design-objectives` — 教学目标与教学重难点的写法模板
- `teaching-process-design` — 教学过程设计的五环节模板
- `case-analysis-objectives` — 教学目标评析的七个切入点
- `case-analysis-process` — 教学过程评析：宏观五方面 + 四个专项类型
- `error-attribution-and-improvement` — 错误归因评析与改进建议
- `teaching-design-set-operations` — 《集合的基本运算》教学设计范例

**制卡策略**：共 76 张。以"为什么 / 怎么用 / 边界在哪 / 和 X 的区别"为主，避免逐字定义背诵；
核心素养五题统一用"含义—内容—表现—举例"四段结构，案例分析四个考点各配辨析卡（如"评教学方式缺点时为何先写优点"）。

**发现的缺口**：材料覆盖数学抽象、逻辑推理、数学建模、直观想象、数学运算五个核心素养，缺课标六大素养中的**数据分析**——已记入 Gaps 并写入 outcomes。

**下一步建议**：先在 Web UI 完成首轮复习建立基线；案例分析类卡片（case-analysis-process / case-analysis-objectives）占分最重，建议优先；
补一份含"数据分析"核心素养的课标材料后再跑一次导入。
